نصب روی گوشی:
1) پوشه را روی یک هاست HTTPS بگذار (Netlify Drop: فقط پوشه را بکش و رها کن؛ یا GitHub Pages).
2) آدرس را در Chrome (اندروید) یا Safari (آیفون) باز کن → Add to Home Screen / Install.
3) کریپتو (Binance) بدون کلید کار می‌کند. برای فارکس/طلا/سهام در ⚙ کلید رایگان Twelve Data را وارد کن.
4) بورس ایران: فعلاً از ⚙ → فایل CSV بارگذاری کن.
